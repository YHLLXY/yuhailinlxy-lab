## 1. 结论先行

| 问题 | 结论 |
|---|---|
| 要不要引入 JS 缓动库（bezier-easing / popmotion / GSAP）？ | **不要。** CSS `cubic-bezier()` / `linear()` + WAAPI `element.animate({easing})` 已覆盖全部需求，引入即超预算 |
| 曲线数值从哪来？ | 用 **Penner 方程的数学定义**自己算 + 用 cubic-bezier 近似值做 CSS 输出。**数值是数学事实，不受版权保护** |
| 能不能直接抄 easings.net 的代码？ | **绝对不能。** 该仓库是 **GPL-3.0**，拷进来会让整个公开仓库被传染成 GPL |
| cubic-bezier 够用吗？ | 对 Sine/Quad/Cubic 够用；对 **Expo / Back / Elastic / Bounce 只是近似**，失真的要用 `linear()` 或多段逼近 |
| 「双曲线并排对照」是不是我们首创？ | **不是。** cubic-bezier.com 早已支持多条曲线同屏对照。我们的差异在**内容**（用在哪/别用在哪/多久），不在对照这件事本身 |

## 2. 已有方案盘点

### 2.1 `ai/easings.net` —— 数据最全，但许可有毒

| 项 | 实测结果 |
|---|---|
| 仓库 | https://github.com/ai/easings.net |
| 许可 | **GPL-3.0**（API 返回 `spdx_id: GPL-3.0`） |
| 星数 | 8,705 |
| 数据文件 | `src/easings.yml`（4,644 B） |

数据结构是每条三个字段：

```yaml
- name: easeOutExpo
  css:  cubic-bezier(0.16, 1, 0.3, 1)
  maths: |-
      return x === 1 ? 1 : 1 - Math.pow(2, -10 * x);
```

文件按族排列，实测确认存在：Sine / Quad / Cubic / Quart / Quint / Expo / Circ 七族，每族 In、Out、InOut 三条（后续还有 Back / Elastic / Bounce，未逐条读取）。

**关键洞察**：`css` 字段是`maths` 的**四点贝塞尔近似**，不是原函数。社区里已有 PR 指出这些近似值与原始定义「fundamentally different」——也就是说，业界最权威的这张表本身就承认近似误差。

**许可边界**：
- ❌ 不能复制它的 `.yml`、`.pug`、`.ts`、CSS 文件
- ✅ 可以用 `cubic-bezier()` 的四个数字（数学事实）与 Penner 方程（1980 年代公开发表，非本仓库原创）
- ✅ 可以读它的**组织形式**（name/css/maths 三段式）作为思路，但自己重写数据结构

### 2.2 `cubic-bezier.com` —— 对照交互的先驱

- 作者 Lea Verou，2011 年发布，起因是当时所有工具都把控制点限制在 0–1 范围，无法表达「回弹」类曲线
- 它**支持多条曲线同屏对照**

→ 所以本站的「双曲线同帧对照」**不是原创交互**，不能当卖点。真正的差异必须落在：每条曲线的**使用场景、禁用场景、搭配时长**，以及「这里到底该不该动」这个判断层。

## 3. 平台能力：为什么不需要库

### 3.1 `cubic-bezier(x1, y1, x2, y2)`

两点固定为 (0,0) 与 (1,1)，中间两点可超出 0–1 做回弹。**缺点：只有 4 个控制点**，对指数/弹跳类曲线只能拟合，误差在「急停」段最明显。

### 3.2 `linear(...)` —— 精确逼近任意曲线

CSS `linear()` 允许用任意多个采样点定义缓动：

```css
/* 用若干采样点精确复现 easeOutExpo */
transition-timing-function: linear(0, 0.5 10%, 0.75 25%, ... , 1);
```

对 Expo / Back / Elastic / Bounce 这类 cubic-bezier 拟合不良的曲线，用 `linear()` 采样可以做到肉眼无差。
→ **M1 的实现策略：数据文件里同时存 `bezier` 与可选的 `linear` 采样数组，优先用 bezier，失真明显时降级/升级为 `linear()`。**

### 3.3 WAAPI —— 播放控制不用自己写

```js
el.animate(keyframes, { duration, easing, fill: 'both' })
```

提供 `play()` / `pause()` / `reverse()` / `finished` Promise / `currentTime` 精确控制，
**不需要任何第三方动画库**来实现「重播」「并排同帧启动」「暂停在某一点」。

## 4. 许可与原创性边界（写进代码注释）

| 可用 | 不可用 |
|---|---|
| 数学定义、cubic-bezier 四元组、时长数值 | 他人源码、组件结构、CSS 文件 |
| 通用交互范式（点击播放、复制 CSS） | 他人的文案、图标、配色方案 |
| Penner 方程（公开发表） | easings.net 的 yml/pug/ts 内容 |

**自检口径**：如果一段代码是从某个仓库里读出来直接敲进来的，就是不能用。

## 5. 落到 M1 的具体取舍

1. **数据文件自己写**：`src/data/easings.ts`，字段至少包含
   `id / name(中英) / bezier[4] / category(进场|退场|位移) / useWhen / avoidWhen / pairedDuration`
2. **18 条**来自本地速查表（`12-自建速查\缓动曲线速查.md`：进场 7 / 退场 4 / 位移 7），
   不照搬 easings.net 的 30 条全集——**取舍本身就是编辑立场**
3. **渲染用原生 CSS**，播放用 WAAPI，复制用 `navigator.clipboard.writeText`（失败回退 `document.execCommand`）
4. **不加任何依赖**，M1 结束后重新核对 JS 预算
