## 4. 页面规格

### `/easing` 缓动曲线

- **数据**：**18 条**曲线，分三组（进场 7 / 退场 4 / 位移 7），每条含名称、`cubic-bezier` 值、手感描述、典型用途
- **交互一**：点卡片 → 用该曲线播放一个 20px 上移 + 淡入的小方块
- **交互二（核心）**：勾选两条曲线 → **并排同时播放同一动画**，肉眼对比手感差异
- **交互三**：一键复制 `cubic-bezier(...)`
- **结尾**：「什么时候不该用」——例如回弹曲线不适合高频重复出现的元素

> 为什么对比是核心：**「手感」只能通过对比感知**，单独看一条曲线什么都判断不出来。这正是 easings.net 缺的。

### `/timing` 时长与节奏

- **基准表**：**11 个场景**（按钮 hover / 开关 / Tooltip / 下拉 / Modal / Drawer / Tab / 列表增删 / 路由转场 / 骨架屏 / 数字滚动），每行给推荐时长与缓动
- **每行「试一下」**：点击后按该场景的规格实时播放一次（如 Modal = 遮罩 200ms fade + 内容 250ms scale 0.96→1）
- **Stagger 对比**：40ms / 80ms / 120ms 三档错峰并排播放，直观看出「节奏」
- **结尾**：编排模式与「进快退更快」的配比理由

### `/rules` 性能红线

- 5 条红线（只动 transform/opacity、16ms 预算、will-change 正确用法、IntersectionObserver、尊重系统设置）
- **核心 demo**：`transform` vs `left` **并排同时跑 60 个元素**（小屏 24 个），各自显示实时帧率读数
- 第二个 demo：`will-change` 加了 / 没加 的差异
- 第三个 demo：`prefers-reduced-motion` 生效前后的对比

### `/` 首页

- 一句话定位 + 三个模块卡片（卡片本身用统一曲线进场，是本页唯一动效）
- 「为什么做这个」：一段短话，说明这不是素材库
- 底部：回到作品集的链接

**偏离 ①：项目位置 E: → C:（重要）**

原计划建在 `E:\homework\开发\动效实验室`。实际 `npm install` 在 E: 上跑了 25 分钟仍未落盘（node 进程停滞，无网络连接、CPU 空转）。实测：

| 盘 | 文件系统 | 类型 | 小文件写入（500 × 4 KB） |
|---|---|---|---|
| E: | **exFAT** | 可移动 | 20.7 s（**24 文件/秒**） |
| C: | NTFS | 固定 | 0.31 s（**1590 文件/秒**） |

exFAT 不支持符号链接，小文件写入慢 **66 倍**。同一份 `npm install` 在 C: 上 **51 秒**完成（200 个包、9747 个文件）。且 E: 是本轮会话中已被拔插过的移动盘（F: 那次直接导致 agent 崩溃）。故整体迁至 `C:\dev\动效实验室`，19 个源文件逐字节校验一致后删除 E: 副本。

> 教训已具备复用价值：**Node 项目不要放在 exFAT / 可移动盘上**。

**偏离 ②：焦点环用实线而非虚线**（原定沿用作品集的 dashed 样式）。2px 虚线在低 DPI 下锯齿明显，实线在深浅两种底色上更稳。若要全站视觉统一可改回。
